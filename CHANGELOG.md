# Changelog

All notable changes to the CE-RISE Data Quality Framework Data Model will be documented in this file.

## [0.0.2] - 2026-05-12

### Fixed
- Namespaced LinkML class, slot, and enum identifiers for import-safe use alongside the uncertainty quantification and metrological traceability utility models.

## [0.0.1] - 2026-05-11

### Added
- Initial project structure for the CE-RISE Data Quality Framework Data Model
- LinkML model structure for data quality assessments, data characterization, quality profiles, criterion assessments, metrics, diagnostics, quality issues, remediation actions, uncertainty translations, aggregations, and evidence references
- Repository metadata for Codeberg Pages, Zenodo, citation, and GitHub release mirroring
